## Freeze policy

Game development continues on `plushbound-game-development` using data, modules, manifests, assets, maps, events, and public engine contracts.

Core engine changes require a demonstrated bug, compatibility issue, performance issue, save-migration requirement, or genuinely missing capability. Any such change must keep all existing acceptance/freeze gates green.

The first game-layer package begins with Plustopia, the Sunny Plains of Elyndor, the four starter Plush Guardians, Lio the Waystitch Keeper, the first Frayling encounters, and the quest **A Thread Begins**.
